# Online Shop CLI App

This is a simple backend-style CLI application built with Python and SQLite.

## Features:
- Add users
- Add orders
- View users
- View orders
- Calculate total spending
- Count orders per user

## Tech Stack:
- Python
- SQLite

## How to Run:
1. Run setup.sql to create database
2. Run main.py

## Description:
This project simulates a simple backend system for managing users and orders.
